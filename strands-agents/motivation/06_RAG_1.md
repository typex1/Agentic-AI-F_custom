# 08 — Adaptive Structured RAG (NL2SQL)

**Python file:** [`../06_RAG_1.py`](../06_RAG_1.py)

## Learning objective
Build a retrieval-augmented agent that converts natural-language questions into
SQL, executes them, and self-corrects when the database returns an error.

## Why it matters
This is a realistic, end-to-end technical pattern: grounding an LLM in real
structured data (schema retrieval) so it generates correct, executable queries —
and recovering from mistakes automatically. It's a port of an official Strands
sample, adapted to run within this environment's limited permissions.

## What this example demonstrates
- A `get_schema` tool that retrieves the database schema (the "retrieval" in
  structured RAG) to ground SQL generation.
- A `run_sqlite_query` tool that executes SQL and returns errors so the agent
  can **self-correct** and retry.
- A self-contained SQLite database built in-process (no external setup).
- Adapting a Bedrock/Claude + Athena sample to Nova Lite + local SQLite under
  restricted permissions.

## Key concepts
Structured RAG, NL2SQL, schema grounding, self-correcting tool loops, permission-
aware adaptation of a reference architecture.
