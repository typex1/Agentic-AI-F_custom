# Video Transcripts

Transcripts of the ten latest videos from the Matt Pocock YouTube channel (https://www.youtube.com/@mattpocockuk/videos), stored as OKF `video_transcript` concepts. Each entry links to the concept document; the YouTube video id is embedded in the filename and frontmatter.

* [Learn anything with the /teach skill](Learn_anything_with_the_teach_skill_s5T5oQJcJ6U.md) - Matt introduces a `teach` skill that turns a coding agent into a personal tutor. (published 2026-06-08)
* [Can Cursor's HARDCORE Review Skill Stop The Slop?](Can_Cursors_HARDCORE_Review_Skill_Stop_The_Slop_mh5XZ-L5SFQ.md) - Matt tests the Cursor team's "thermonuclear code quality review" skill on his own Sandcastle repo, reviewing the last five PRs merged to main. (published 2026-05-28)
* [9 Things People Get Wrong With My /grill-* skills](9_Things_People_Get_Wrong_With_My_grill-_skills_UzMNBN6xLLA.md) - A guide to using the Grill Me and Grill with Docs planning skills well. (published 2026-05-25)
* [/handoff is my new favourite skill](handoff_is_my_new_favourite_skill_dtAJ2dOd3ko.md) - A deep dive on the `handoff` skill, which compresses the current session's context into a disposable markdown file (saved to the OS temp directory) so a fresh agent can continue the work. (published 2026-05-21)
* [I stopped using /grill-me for coding. Here's what I use instead:](I_stopped_using_grill-me_for_coding._Heres_what_I_use_instead_6BB6exR8Zd8.md) - Matt introduces Grill with Docs, which merges the Grill Me interview skill with a "ubiquitous language" layer borrowed from domain-driven design. (published 2026-05-14)
* [Anthropic's "dedicated monthly credit" is actually a huge cut](Anthropics_dedicated_monthly_credit_is_actually_a_huge_cut_lNOQaakmyDU.md) - Matt breaks down Anthropic's announcement that, starting June 15, paid Claude plans receive a separate "dedicated monthly credit" for programmatic/AFK usage (the Claude Agent SDK, `claude -p`, GitHub Actions, and third-party apps) split apart from human-in-the-loop usage (Claude Code, Claude.ai, Co-work). (published 2026-05-13)
* [New Skills! /handoff, /prototype, /review and /writing-* | Skills Changelog](New_Skills_handoff_prototype_review_and_writing-_Skills_Changelog_DNqsMXH6Eog.md) - A changelog video (the skills repo just passed 70k stars) covering two new skills: `handoff`, which compacts the current conversation into a temporary handoff document for another agent, and `prototype`, which builds throwaway UI and logic/state-machine prototypes as research spikes. (published 2026-05-12)
* [Burn through the backlog from hell with /triage](Burn_through_the_backlog_from_hell_with_triage_MzWIIlx0Gpc.md) - Matt presents the `triage` skill for turning messy team and open-source backlogs (GitHub issues, Jira) into actionable work. (published 2026-05-07)
* [I Open-Sourced My Own AFK Software Factory](I_Open-Sourced_My_Own_AFK_Software_Factory_E5-QK3CDVQM.md) - Matt launches Sandcastle, an open-source TypeScript library for orchestrating AI coding agents in isolated sandboxes (such as Docker) so they can run away-from-keyboard in parallel without dangerous unsandboxed "yolo" permissions. (published 2026-04-30)
* [How To De-Slop A Codebase Ruined By AI (with one skill)](How_To_De-Slop_A_Codebase_Ruined_By_AI_with_one_skill_3MP8D-mdheA.md) - Matt argues that AI accelerates software entropy and offers his "improve codebase architecture" skill as the cure. (published 2026-04-29)
